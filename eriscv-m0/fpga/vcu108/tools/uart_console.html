UART boot and
serial console.

A local-only Chromium console for the CP2105 Standard UART. Select the port explicitly, upload a word-addressed IMEM image, then interact with the running M0 firmware.

Before booting: program the FPGA, select UART boot (3'b010), press CPU_RESET, then use Connect and Boot image. The boot protocol is fixed at 115200 baud, 8-N-1, no flow control. RELEASE permanently hands the RX pin to runtime firmware until the next reset; reconnect after a re-arm reset to load another image.

1. Serial connection

Use 115200 for boot. Runtime firmware may use another rate only after reconnecting at that rate.

2. UART boot

Choose freertos_monitor.imem.mem from the board-image build for the FreeRTOS monitor demo.

Boot image sends HOLD → RESET_ADDR → AUTO_INC → WRITE32×N → RELEASE. After RELEASE, boot controls are disabled until a board reset and reconnect.
