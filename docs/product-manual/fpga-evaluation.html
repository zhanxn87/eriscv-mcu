Evaluation boundary. These are post-route FPGA implementation results, not ASIC PPA estimates, guaranteed Fmax, board-I/O timing sign-off, power figures, or a production release statement.

02 / INTERPRETATION

M0 and M1 meet 100 MHz; M2 timing closure is open.

M0

Compact baseline

+0.425 ns WNS. The local-memory control product uses no DSP blocks and 32 BRAM tiles.

M1

Protection and load path

+0.107 ns WNS. M extension and protection logic add LUT, register, and DSP usage while retaining the 100 MHz target.

M2

Compute and memory cost

The 2026-08-04 routed build is fully routed but still misses 100 MHz by 0.050 ns: TNS -0.838 ns and 37 setup failing endpoints. RV32F, System SRAM, and DMA account for the additional resources; 192 BRAM tiles include the 512 KiB banked System SRAM.

DRC

No reported errors

Reports contain CFGBVS/CONFIG_VOLTAGE and DSP pipelining recommendations as Warnings. They are not timing failures, but board constraints and DSP trade-offs require follow-up.

03 / REPORT PROVENANCE

Reproducible artifacts, with one remaining metadata improvement.

  1. Routed evidenceTiming, utilization, clock-utilization, and DRC reports are generated under each product-local VCU108 build directory; build outputs are intentionally not versioned. The reviewed values are transcribed in the linked evidence record.
  2. Timing resultM0 and M1 have positive WNS, zero TNS, and no setup endpoint failures. M2 is fully routed but has WNS -0.050 ns, TNS -0.838 ns, and 37 setup failing endpoints at the 100.010 MHz target.
  3. DRC boundaryThe reports contain warnings but no reported errors. CFGBVS and CONFIG_VOLTAGE must be set correctly before a board-oriented release claim.
  4. Source provenanceThe routed report headers record the tool and device but not a Git SHA. Future FPGA report scripts shall emit the exact source revision and constraint hash.

IMPORTANT

Positive internal setup slack does not validate external I/O timing, bitstream programming, reset sequencing, UART output, or JTAG debug on physical hardware.
